刷写控制台

当前目标：GD32。页面会使用 cmd=0x00 发送数据，最后自动写 CTRL=0xF7。协议格式：cmd(1) + seq(2) + total_size(4) + payload + crc占位4。
等待选择文件 0%
浏览器要求：建议用 Chrome / Edge / Android Chromium，并通过 http(s) 页面打开。某些桌面浏览器的 file:// 下 Web Bluetooth 会被拒绝。若目标为 ESP32，一键刷写最后一步会触发设备重启，BLE 断开属于正常现象。
默认 payload 已提高到 480B；如果首包就失败，说明当前系统实际协商到的 ATT MTU 较小，把 payload 手动降回 240B 或更低再试。
